# Memory format

claude-memory reads and writes plain Markdown under the Claude Code config dir (`~/.claude` or `$CLAUDE_CONFIG_DIR`). Nothing here needs a database: delete the search cache and it is rebuilt.

## Layout

```
~/.claude/
├── projects/<project slug>/            one per project; the slug is the project path with every non-alphanumeric character replaced by "-"
│   ├── <session id>.jsonl              transcripts (written by Claude Code)
│   ├── memory/                         long-term memory (Claude Code's auto memory)
│   │   ├── MEMORY.md                   index, loaded into every session
│   │   ├── index_<topic>.md            sub-indexes; index_archive.md marks notes as archived
│   │   ├── <type>_<topic>.md           one fact per note
│   │   └── REGISTRY.md                 generated by /sleep, not loaded into sessions
│   └── digests/                        session diary
│       ├── days/YYYY-MM-DD/<session id>.md
│       ├── weeks/YYYY-Www.md
│       ├── months/YYYY-MM.md
│       ├── wraps/YYYY-MM-DD/<HHMM>-<window>.md     /wrap summaries
│       └── live/YYYY-MM-DD.md                      short log of sessions from the live registry
├── state/                              short-lived files
│   ├── last-session-<project slug>.md
│   ├── clear-handoff-<window>.md, wrap-<window>.md  consumed by the next session after /clear
│   ├── live/sessions/<session id>.json, live/events.jsonl
│   └── claude-memory.log
└── claude-memory/                      the installed hooks and tools
```

## A note

```markdown
---
name: project_checkout_timeout
description: "ACME-412 checkout times out when the payment provider answers slower than 10 s"
metadata:
  type: project
  status: active
  title: ACME-412 checkout timeout on slow payment provider
  next: "2026-11-20: retry implemented, tests green; next: load test in staging, then PR"
  group: Checkout
  modified: 2026-11-20T15:30:00.000Z
---

**2026-11-18.** What was found, with numbers and links.

**2026-11-20.** What changed. Related: [[reference_payments_sandbox]].
```

| Field | Read by | Meaning |
|---|---|---|
| `name` | memsearch, lint | the note's slug; must equal the file name without `.md` |
| `description` | memsearch, lint, registry | one line used to decide relevance; required |
| `type` | memsearch, lint | `user` (who the user is), `feedback` (how to work, with **Why** / **How to apply**), `project` (ongoing work), `reference` (where things are) |
| `status` | active_tasks, lint, registry | `active` puts the note in the task list at session start and exempts it from the index; `done` when finished |
| `title`, `next` | active_tasks | the task's line: title and the current state and next step, with a date |
| `group` | active_tasks | optional heading to group tasks under |
| `modified` | active_tasks, memsearch | ISO timestamp; sorts tasks and drives `--older-than`. Claude Code writes it for notes it edits |

The parser reads flat `key: value` lines and ignores nesting, so fields can sit at the top level or under `metadata:`.

## Links and indexes

- `[[name]]` links notes by `name`. An unresolved link is fine: it marks a note worth writing later.
- `[text](file.md)` links are checked by `memsearch lint`; a broken one is reported.
- Every note except active tasks should be linked from `MEMORY.md` or an `index_*.md` sub-index; `memsearch lint` reports orphans.
- Notes linked from `index_archive.md` are archived: `memsearch ls --active` hides them and `--archived` shows only them. Archive old topics instead of deleting them.

## Diary entries

Written by the diary hook; you rarely edit them by hand.

```markdown
### 15:10–16:40 · Checkout retry with idempotency key · ACME-412
- Done: retry with the same idempotency key in checkout/pay.js, tests added
- Decided: one retry, not a longer timeout — a 30 s timeout keeps request threads busy
- Open: load test in staging, then PR
```

The labels `Done:`, `Decided:`, `Open:` and the roll-up headings (`## Loose ends`) stay in English because recall looks for them; the text itself is written in the language of the session.
